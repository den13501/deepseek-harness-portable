# DSH Portable 繁體中文測試版

這是未簽章衍生測試包，不是官方發行版。版本與來源提交見 BUILD-INFO.json；若 dirty 為 true，提交無法完整定位此成品來源。當次靜態政策檢查見 POLICY-CHECK.json，不等於公司環境驗收或零外傳證明。

完整解壓縮到本機可寫入短路徑後，執行 Start-DSH.cmd，不要直接開 app 內的 EXE。不需要系統管理員權限；遇到端點防護阻擋時交由 IT 處理，不要繞過。

首次啟動建立獨立 data 與 workspace。設定繁體中文，選擇工作區並建立對話；模型只使用核准端點與測試資料。請分別驗證多輪／取消、重啟保存、工具讀寫、Office／PDF、作業系統相容性與核准的網路監控。

固定政策停用五個已知 Harness 內建收集／額外模型欄位模組，但不控制第三方外掛與正常推論服務的資料處理。Portable 不保證完全無痕，系統與工具可能留下暫存。

ZIP.sha256 驗證整包；SHA256SUMS.csv 記錄包內其他檔案的相對路徑與雜湊。此包不帶既有個人資料；啟動後 data 可能含憑證與聊天，workspace 可能含工作文件，不可把已使用目錄整包重新分享。保留 app 內授權與第三方聲明。

## 更新既有免安裝包

1. 保留可信來源的新 ZIP 與校驗檔，驗證 SHA-256，再將新包完整解壓到另一個空目錄。不要先啟動新包，不要把舊 data 複製進新包。
2. 關閉所有 DSH 視窗及 Desktop Host，不要在更新期間重新開啟；也不要直接執行內部 EXE。備份作業需要舊程式、完整 data 與新版程式暫存所需的可用空間。
3. 從乾淨新包執行 Check-Update.cmd，輸入舊包的完整目錄。預檢不修改新舊包；來源必須比目標版本新，且檔案清單、雜湊、離線政策與 runtime 版本必須一致。
4. 從同一乾淨新包執行 Update-DSH.cmd，輸入舊包目錄，確認資訊後輸入 UPDATE。工具先在舊包 portable-backups 建立並驗證程式與完整 data 快照，再整批替換程式；顯示完成後記下 backupId。
5. 繼續使用原來舊包位置的 Start-DSH.cmd。data 與 workspace 路徑未變，供應商、憑證、profile、Skills、MCP 設定及聊天不會被預設設定覆蓋；重啟後仍須確認模型、外掛相容性與實際工具呼叫。

這是本機、離線、需確認的更新，不是背景下載或官方自動更新。只支援本衍生包的 app、data、workspace 結構與預期啟動器；不支援直接更新一般安裝版或猜測其他資料根目錄。根目錄的自訂檔案不刪除；新版管理的啟動器、說明、版本與雜湊檔會更新。來源若已含 data、workspace 或其他額外檔案會拒絕。資料內的符號連結／junction 會拒絕，不能靜默略過。

使用者 Skills 可能在 data/home/skills、workspace 的 .dsh/skills 或 .agents/skills，以及包外 agentsHome 或自訂目錄。MCP 執行檔、外掛本地來源、工作區可能使用絕對路徑；工具不搬移、不重寫、不下載這些外部資源，也不保證跨電腦可用。外部目錄與工作文件請另外備份。第三方外掛的版本相容性可能改變，保留設定不代表外掛一定可執行。

## 回復與中斷處理

保留乾淨新包，從其中執行 Restore-DSH.cmd，輸入原使用目錄與 backupId，確認後輸入 RESTORE。回復會還原舊程式及升級前完整 data；升級後新增的聊天或設定不會自動合併，而是保留在該次回復證據目錄的 displaced/data。workspace 與包外檔案不回復。不要只換回舊 EXE：新版資料格式不保證可降版讀取。

程式替換失敗時會嘗試自動回復程式並保留證據；若自動回復失敗或斷電，請保持 DSH 關閉，使用乾淨新包的回復入口。不要刪除 .portable-update.lock 或 profile lock 來強行啟動，也不要移動原使用目錄。回復會驗證快照；發現損毀、其他作業的鎖或仍存活的更新程序即停止。不要在回復前手動刪除備份。

portable-backups 含 API Key、授權資料、聊天及可能的私人文件；新建快照限制為目前 Windows 使用者與 SYSTEM 存取，仍需依組織政策保護磁碟。使用過的目錄與備份不可重新打包或上傳。雜湊只驗證完整性，不證明來源可信；本包仍未簽章。
